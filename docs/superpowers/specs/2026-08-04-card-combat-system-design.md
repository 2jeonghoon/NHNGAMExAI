# 카드 전투 시스템 설계

작성일: 2026-08-04

## 목표

기존의 여섯 일반 전투 명령을 Slay the Spire 방식의 카드 덱으로 전환한다. 플레이어는 항해 중 카드를 획득하거나 제거하며 덱을 성장시킨다. 선장 고유 기술은 카드가 아니며 기존처럼 전투당 한 번 사용할 수 있다.

핵심 목표는 다음과 같다.

- 에너지 3을 사용해 한 플레이어 턴에 여러 카드를 사용한다.
- 10장 시작 덱과 공용 21종, 선장 전용 28종으로 덱 구성의 변화를 만든다.
- 모든 전투에서 카드 보상을 제공하고 항구와 일부 이벤트에서 카드를 제거한다.
- 에너지와 드로우에 영향을 주는 유물, 선원 역할, 선원 특성을 추가한다.
- 대상별 드래그와 카드 애니메이션으로 카드를 플레이한다.
- 어려운 항로의 일반·정예전에서 2~3척의 적 함대와 교전한다.
- 기존 선박 전투 수치, 선장 기술, 유물 보상, 선박 이미지와 분석 기능을 보존한다.

## 범위

### 포함

- 공용 카드 21종
- 선장별 전용 카드 7종, 총 28종

- 에너지, 드로우, 버림, 소멸, 턴 종료와 적 턴

- 에너지 유물 4종
- 갑판장 역할과 에너지 특성 2종
- 하단 손패형 전투 UI와 모바일 재배치
- 카드 관련 분석 기록과 자동·브라우저 테스트

### 제외

- 선장 고유 기술의 카드화
- 항해 중단 후 재접속을 위한 런 저장·복구
- 적 전용 덱이나 적 카드 UI

## 전투 턴 구조

항해 데이터의 `deck`은 카드 ID 배열이며 전투가 끝나도 유지된다. 전투 시작 시 덱을 섞어 전투 전용 상태를 만든다.

- `drawPile`: 뽑을 카드
- `hand`: 현재 손패
- `discardPile`: 사용했거나 턴 종료로 버린 카드
- `exhaustPile`: 소멸하여 이번 전투에서 다시 나오지 않는 카드
- `energy`: 현재 에너지
- `maxEnergy`: 기본 3, 최대 4
- `handSize`: 기본 5, 효과에 따라 변하며 손패 최대치는 8
- `skillReady`: 선장 기술의 전투당 1회 상태
- `turn`: 플레이어 턴 번호
- `enemies`: 살아 있거나 격파된 적 함선 상태 배열. 각 적은 고유 ID와 개별 거리를 가진다.
- 카드가 만드는 명중 보정, 피해 보정, 기동 차단, 비용 감소 등의 임시 효과

턴 순서는 다음과 같다.

1. 전투 시작 시 덱을 섞고 에너지를 채운 뒤 카드 5장을 뽑는다.
2. 플레이어는 에너지가 허용하는 만큼 여러 카드를 사용한다.
3. 카드 사용 시 조건 검사, 에너지 차감, 효과 실행, 버림 또는 소멸 이동을 순서대로 수행한다.
4. 선장 기술은 에너지를 소비하지 않으며 플레이어 턴 중 한 번 사용할 수 있다.
5. `턴 종료`를 누르면 남은 손패를 버리고 살아 있는 적들이 항로별 행동 제한 안에서 차례로 행동한다.
6. 적 함대의 행동이 끝나면 다음 플레이어 턴을 시작하고 에너지를 초기화한 뒤 카드 5장을 뽑는다.
7. 뽑기 더미가 부족할 때만 버림 더미를 섞어 새 뽑기 더미로 사용한다. 소멸 카드는 섞지 않는다.

카드 사용마다 적이 행동하지 않는다. 적 함대는 플레이어가 턴을 종료했을 때만 행동한다.

## 항로별 다중 적 편성

보스전은 기존 이미지와 다단계 구조를 보존한 단일 함선으로 유지한다. 일반·정예전만 항로에 따라 적 함대가 등장한다.

| 항로 | 일반전 | 정예전 | 보스전 |
| --- | --- | --- | --- |
| 잔잔한 무역풍 | 1척 | 1척 | 1척 |
| 폭풍의 사각지대 | 1~2척 | 2척 | 1척 |
| 심연의 마지막 항로 | 2척 | 2~3척 | 1척 |

- 폭풍 항로 일반전의 2척 확률은 Act 1에서 40%, Act 2~3에서 60%다.
- 심연 정예전의 3척 확률은 50%다.
- 한 편성 안에서 적 이름과 선박 이미지는 중복하지 않는다.
- 정예전은 정예함 1척과 일반 호위함 1~2척으로 구성한다. 모든 함선을 정예 수치로 만들지 않는다.
- 2척 편성은 각 함선의 선체·돛·선원·공격력을 같은 항로 단일 적 수치의 65%로 곱한 뒤 반올림한다.
- 3척 편성은 각 함선의 선체·돛·선원·공격력을 같은 항로 단일 적 수치의 50%로 곱한 뒤 반올림한다.
- 전투 전체 금화·악명은 편성 개별 보상을 합산하지 않는다. 같은 항로·노드의 단일 전투 보상을 기준으로 2척은 125%, 3척은 150%를 곱해 한 번 지급한다.
- 기존 나포 추가 보상은 나포한 함선 한 척마다 금화 8·악명 5를 더하되, 항로와 유물 보상 배율은 최종 합계에 한 번 적용한다.

각 적은 플레이어와의 거리 1~3을 별도로 가진다.

- 접근 카드는 지정한 적과의 거리만 1 감소시킨다.
- 회피 카드는 살아 있는 모든 적과의 거리를 1 증가시킨다. 최대 거리는 3이다.
- 접안 조건과 확률은 지정한 적의 거리·돛·선원만 사용한다.
- 한 척을 나포해도 다른 적이 남아 있으면 전투를 계속한다.
- 모든 적의 선체나 선원이 0이 되어 격파·나포되어야 승리한다.

적 턴에는 살아 있는 적이 순서대로 행동하되 직접 공격 수를 제한한다.

- 폭풍 항로는 한 적 턴에 최대 1척만 직접 공격한다.
- 심연 항로는 한 적 턴에 최대 2척만 직접 공격한다.
- 공격하지 않는 적은 접근, 거리 유지, 다음 공격 준비 중 하나를 수행한다.
- 다음 공격을 준비한 적은 플레이어 턴 동안 의도 아이콘과 설명을 표시한다.
- 공격 제한은 살아 있는 적 수보다 우선하며 적 행동 순서는 매 턴 순환해 같은 적만 계속 공격하지 않게 한다.

## 선장 고유 기술

선장 고유 기술은 카드가 아니다. 하단 전투 조작부의 별도 버튼으로 유지한다.

- 에너지를 소비하지 않는다.
- 플레이어 턴 중 원하는 시점에 사용할 수 있다.
- 기존 `skillReady` 상태를 사용해 전투당 한 번으로 제한한다.
- 기술 사용만으로 적 턴이 시작되지 않는다.
- 기존 네 선장의 기술 효과는 변경하지 않는다.
- 이사벨라·마라·빅토르 기술은 현재 초점이 있는 적 한 척을 대상으로 한다.
- 라울 기술은 모든 적과의 거리를 3으로 만들고, 돛 피해는 현재 초점이 있는 적 한 척에 적용한다.
- 초점 대상이 필요한 기술은 기술 버튼을 누른 뒤 적을 선택하며, 취소하면 `skillReady`를 소비하지 않는다.

## 에너지 유물

| 유물 | 등급 | 효과 |
| --- | --- | --- |
| 항해사의 모래시계 | 노말 | 매 전투 첫 턴 에너지 +1 |
| 황동 축전기 | 레어 | 세 번째 플레이어 턴마다 에너지 +1 |
| 밀수업자의 도르래 | 에픽 | 매 턴 처음으로 비용 0 카드를 사용하면 에너지 +1 |
| 폭군의 함대 인장 | 레전드 | 최대 에너지 +1, 매 턴 드로우 5장에서 4장으로 감소 |

최대 에너지는 4로 제한한다. 첫 턴 또는 조건부로 얻는 임시 에너지는 최대 에너지를 넘어갈 수 있다.

## 에너지 선원

### 갑판장 역할

갑판장 여러 명을 보유해도 가장 높은 등급의 효과만 적용한다.

| 등급 | 효과 |
| --- | --- |
| 노말 | 전투 첫 턴 에너지 +1 |
| 레어 | 첫 턴 에너지 +1, 카드 1장 추가 드로우 |
| 에픽 | 첫 번째와 두 번째 턴에 에너지 +1 |
| 레전드 | 최대 에너지 +1, 첫 턴 카드 1장 추가 드로우 |

### 에너지 특성

- `절약가`: 매 전투 첫 카드의 비용을 1 낮춘다.
- `분발`: 매 전투 한 번, 에너지가 0이 되면 에너지 1을 회복한다.

같은 특성을 가진 선원이 여러 명이어도 효과는 한 번만 적용한다. 갑판장과 유물의 최대 에너지 증가는 합산하되 최대 에너지 4 제한을 적용한다.

## 카드 보상

모든 전투 승리 후 다음 순서로 보상을 처리한다.

1. 금화, 악명과 남은 선체를 표시한다.
2. 현재 선장이 획득할 수 있는 카드 3장을 제시한다.
3. 플레이어는 카드 1장을 획득하거나 건너뛴다.
4. 정예·보스라면 기존 유물 보상을 이어서 처리한다.
5. 항로로 복귀하거나 다음 해역으로 진입한다.

후보 세 장 안에서는 같은 카드가 중복되지 않는다. 카드 등급은 기존 `RARITIES`의 노말·레어·에픽 가중치를 남은 후보에 맞춰 재정규화한다. 카드 후보가 부족하면 가능한 수만 표시하며, 후보가 없으면 카드 선택을 건너뛴다. 이미 덱에 있는 카드는 다시 획득할 수 있다.

## 덱 열람과 제거

- 우측 선박 패널에 `덱 N장` 버튼을 추가한다.
- 항해 중 언제든 전체 덱과 카드별 보유 수량을 확인할 수 있다.
- 카드를 제거할 수 있는 곳은 항구와 카드 제거를 명시한 일부 이벤트뿐이다.
- 항구 제거 비용은 12금화에서 시작해 이번 항해에서 제거할 때마다 8금화 증가한다.
- 덱이 5장이면 더 제거할 수 없다.
- 제거 전에 카드명과 비용을 포함한 확인 창을 표시한다.
- 제거는 되돌릴 수 없고 별도 보상을 제공하지 않는다.

## 하단 손패 UI

승인된 UI는 하단 손패형이다.

- 해전 캔버스 아래 첫 줄에 현재·최대 에너지, 덱·버림·소멸 수량, 선장 기술, 턴 종료 버튼을 배치한다.
- 두 번째 줄에 현재 손패를 카드 형태로 표시한다.
- 카드에는 에너지 비용, 이름, 계열, 효과 수치와 소멸 여부를 표시한다.
- 사용할 수 없는 카드는 비활성화하고 부족한 에너지, 돛, 거리, 수리도구 또는 카드 고유 조건을 설명한다.
- 추가 드로우를 고려해 손패 최대치를 8로 제한한다.
- 모바일에서는 카드가 2열로 재배치되고 마지막 홀수 카드는 한 행을 사용한다.
- 카드 사용 후 기존 포격·피격 애니메이션과 전투 로그를 갱신하되 적 턴은 시작하지 않는다.

### 대상별 드래그

각 카드 정의는 다음 `targetType` 중 하나를 가진다.

- `enemy`: 포격, 사슬탄, 접안, 단일 저주. 살아 있는 적 함선 한 척에 놓는다.
- `self`: 수리와 자기 강화. 플레이어 함선에 놓는다.
- `sea`: 기동, 드로우, 바람 조작. 바다 중앙의 전술 영역에 놓는다.
- `allEnemies`: 광역 공격과 광역 저주. 바다 중앙의 광역 영역에 놓는다.

드래그는 Pointer Events로 마우스와 터치를 함께 지원한다.

1. 카드를 누르면 손패 위로 떠오르고 1.05배 확대된다.
2. 드래그 중 현재 카드의 유효한 대상만 금색 테두리와 대상 아이콘으로 강조한다.
3. 유효한 대상에 놓으면 카드가 대상 방향으로 회전·축소하며 220ms 동안 날아간다.
4. 카드 비행이 끝나면 효과를 계산하고 기존 포격·수리·기동 효과를 실행한다.
5. 잘못된 위치에 놓거나 사용 조건이 바뀌면 180ms 동안 손패로 튕겨 돌아오며 카드가 흔들린다. 에너지와 카드 위치는 바뀌지 않는다.
6. 광역 카드는 바다 중앙에 도착한 뒤 각 적에게 80ms 간격으로 시각 효과를 퍼뜨린다. 전투 수치는 애니메이션과 분리해 한 번에 적용한다.

`prefers-reduced-motion: reduce`에서는 확대, 회전, 비행, 흔들림을 제거하고 대상 강조와 짧은 투명도 전환만 사용한다.

키보드 조작은 다음과 같다.

- `1`~`8`: 해당 위치의 카드를 선택
- 방향키 또는 Tab: 유효 대상 사이 이동
- `Enter`: 선택한 대상에 카드 사용
- `Escape`: 카드 또는 선장 기술 대상 선택 취소
- `Q`: 선장 고유 기술
- `E`: 턴 종료
- 기존 `F`, `S`, `A`, `D`, `R`, `B` 고정 명령 단축키는 제거

## 코드 경계

### 카드 정의

`CARD_DEFINITIONS`는 카드 ID를 키로 사용하며 이름, 계열, 비용, 등급, 선장 제한, 소멸 여부, `targetType`, 표시용 설명과 효과 ID를 가진다. 카드 수치와 표시 문구가 서로 어긋나지 않도록 동일 정의에서 렌더링과 실행 정보를 가져온다.

### 덱 엔진

덱 엔진은 카드 효과를 알지 않는다. 섞기, 드로우, 버림, 소멸, 손패 제한, 에너지 초기화와 턴 전환만 담당한다. 테스트에서 DOM 없이 실행할 수 있는 순수 함수 중심으로 구성한다.

### 카드 실행기

카드 실행기는 카드와 대상의 사용 조건을 검증하고 기존 포격·사슬탄·접근·회피·수리·접안 계산을 호출한다. 조건 검사는 UI 비활성화, 드롭 대상 강조와 실제 실행에서 같은 함수를 사용한다. 이를 통해 돛이 0인 상태의 키보드 우회도 차단한다.

### 적 편성 및 대상 제어

적 편성 생성기는 항로·노드 종류·Act에 따라 1~3척을 만들고 편성 크기 배율을 각 함선에 적용한다. 대상 제어기는 살아 있는 적, 개별 거리, 현재 초점, 적 의도와 항로별 직접 공격 제한을 관리한다. 단일 적 전투도 길이 1인 같은 배열 경로를 사용한다.

### 드래그와 애니메이션

드래그 제어기는 포인터 캡처, 카드 위치, 유효 대상 강조와 취소를 담당하고 카드 효과를 직접 실행하지 않는다. 유효한 드롭이 완료되면 카드 실행기에 카드 인스턴스 ID와 대상 ID를 전달한다. 애니메이션 완료 콜백이 중복 호출되어도 같은 카드 인스턴스는 한 번만 실행하도록 실행 토큰을 사용한다.

### 보상과 덱 UI

현재 모달과 DOM 생성 도우미를 재사용해 카드 3택, 덱 목록, 제거 확인을 렌더링한다. 전투 UI는 기존 `actionDock`을 확장한다. Canvas 2D 해전 렌더링은 1~3척의 적 함선, 각 함선 HUD·거리·의도·드롭 대상 경계를 그리도록 확장한다.

## 예외와 불변 조건

- 에너지나 사용 조건이 부족하면 카드가 이동하거나 비용이 차감되지 않는다.
- 전투가 끝나는 카드라면 남은 효과와 적 턴 예약을 즉시 중단한다.
- 빈 뽑기 더미만 버림 더미와 섞으며 소멸 카드는 재순환하지 않는다.
- 손패는 8장을 넘지 않고 초과 드로우는 뽑기 더미에 남긴다.
- 알 수 없는 카드 ID는 UI에서 제외하고 게임 로그에 기록한다.
- 덱은 5장 미만으로 제거할 수 없다.
- 선장 전용 카드는 다른 선장의 보상 후보에 포함하지 않는다.
- 비용과 에너지는 음수가 되지 않는다.
- 전투 잠금 상태, 모달 표시 중 또는 적 턴에는 카드와 선장 기술을 사용할 수 없다.
- 카드 효과로 플레이어가 패배하면 후속 효과와 적 턴을 중단한다.
- 격파·나포된 적은 드롭 대상과 적 행동 순서에서 즉시 제외한다.
- 유효하지 않은 대상이나 취소된 드래그는 에너지, 손패, 전투 수치를 바꾸지 않는다.
- 한 카드 인스턴스는 드래그·키보드·애니메이션 콜백이 겹쳐도 한 번만 실행한다.
- 광역 피해는 모든 대상의 결과를 먼저 계산한 뒤 한 번에 적용하고 승리·보상을 한 번만 판정한다.

## 분석 기록

기존 명령 통계의 호환성을 위해 각 카드는 포격, 사슬탄, 접근, 회피, 수리, 접안 계열로 집계한다. 선장 기술은 기존처럼 별도 집계한다.

추가 기록 항목은 다음과 같다.

- 카드별 사용 횟수
- 항해 중 획득한 카드 ID
- 항해 중 제거한 카드 ID
- 사용한 총 에너지와 카드당 평균 에너지
- 전투별 플레이어 턴 수
- 전투별 적 함선 수, 격파 수와 나포 수
- 단일 대상·광역 카드별 적중 대상 수
- 항해 종료 시 덱 목록

기존 분석 저장소는 새 필드를 선택적으로 취급해 이전 기록도 계속 읽을 수 있어야 한다.

## 테스트 전략

### 단위 테스트

- 10장 시작 덱의 수량
- 선장별 카드 보상 풀과 다른 선장 카드 배제
- 공용 21종, 선장별 7종과 전체 49종 카드 정의의 중복 ID 검사
- 5장 드로우, 에너지 3, 턴 종료와 버림
- 버림 더미 재순환과 소멸 카드 제외
- 손패 8장 제한
- 각 카드의 비용, 사용 조건과 핵심 효과
- 카드마다 적이 행동하지 않고 턴 종료 후 항로별 공격 제한 안에서 함대가 행동하는지
- 선장 기술이 에너지 없이 전투당 한 번만 실행되는지
- 에너지 유물, 갑판장과 특성의 중첩 및 최대 에너지 제한
- 카드 획득, 건너뛰기, 항구 제거 비용과 최소 덱 크기
- 알 수 없는 카드 ID와 전투 종료 중단 처리
- 항로·Act·노드 종류별 1~3척 편성 확률과 보스 1척 고정
- 2척 65%, 3척 50% 능력치 배율과 125%·150% 보상
- 적별 거리, 접근 대상, 전체 후퇴, 개별 나포와 전원 격파 승리
- 광역 카드 7종의 모든 생존 적 적용과 단일 승리·보상 판정

### 통합·브라우저 테스트

- 카드 드래그와 `1`~`8`·대상 선택 단축키가 같은 실행 경로를 사용하는지
- `enemy`, `self`, `sea`, `allEnemies` 드롭 대상과 잘못된 드롭 취소
- 카드 선택·비행·복귀·광역 분산 애니메이션과 reduced-motion 대체
- `Q` 선장 기술과 `E` 턴 종료
- 비활성 카드의 이유가 표시되는지
- 전투 승리 후 카드 보상과 정예·보스 유물 보상이 순서대로 이어지는지
- 덱 열람과 제거 확인 창
- 데스크톱 하단 손패 배치와 320px 모바일 2열 배치
- Canvas에 1~3척 적 HUD·거리·의도·드롭 영역이 겹치지 않는지
- 기존 포격 효과, 선박 이미지, 유물, 항해 진행과 분석 화면 회귀 검사

## 성공 기준

- 플레이어가 한 턴에 에너지 3을 사용해 여러 카드를 낼 수 있다.
- 플레이어가 턴을 종료했을 때만 적 함대가 항로별 직접 공격 제한 안에서 행동한다.
- 폭풍·심연 항로의 일반·정예전에서 정의된 확률과 배율로 2~3척 적 편성이 등장하고 보스는 1척을 유지한다.
- 선장 기술은 카드와 독립적이며 전투당 한 번만 사용된다.
- 모든 전투에서 유효한 카드 3택 또는 건너뛰기 흐름을 제공한다.
- 선택한 선장의 전용 카드만 등장한다.
- 항구에서 비용을 지불해 덱을 최소 5장까지 줄일 수 있다.
- 에너지 유물과 선원 효과가 명시된 중첩·상한 규칙대로 작동한다.
- 하단 손패 UI가 데스크톱과 320px 화면에서 겹침이나 잘림 없이 작동한다.
- 카드를 유효한 대상에 드래그하거나 키보드로 대상을 선택해 사용할 수 있고, 취소 시 상태가 변하지 않는다.
- 광역 카드 7종이 모든 생존 적에게 한 번씩 적용되고 승리·보상이 중복되지 않는다.
- 기존 게임의 비카드 기능에 회귀가 없다.

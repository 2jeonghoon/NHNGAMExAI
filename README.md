# 항해의 끝: 해적왕의 유산

대해적시대를 배경으로 한 브라우저 로그라이크 게임입니다. 한 명의 선장과 작은 배로 출항해 무작위 분기 항로를 선택하고, 선박과 선원을 성장시키며 세 개의 해역 끝에 있는 전설의 보물에 도전합니다.

## 플레이 가능한 빌드

저장소 루트의 `index.html`을 브라우저에서 열거나 아래처럼 정적 서버를 실행합니다.

```bash
python3 -m http.server 5173
```

브라우저에서 `http://localhost:5173`을 엽니다. 별도 설치나 빌드 과정은 필요하지 않습니다.

## 구현된 게임 시스템

- 고유 능력과 전용 스킬이 있는 선장 3명, 그리고 첫 승리(해적왕 등극) 시 해금되는 숨겨진 선장 1명
- 난이도가 다른 항로 3종(표준·험로·극한)을 출항 전에 선택하는 구조. 각 항로는 고유한 3개 해역·보스로 구성되며, 이전 항로를 완주해야 다음 항로가 해금됨
- 매 항해마다 달라지는 3개 해역의 분기 항로
- 일반 전투, 정예 전투, 선택형 조우, 항구, 보물, 보스 노드
- 식량, 식수, 사기, 선체, 돛, 금화를 연동한 생존 자원 관리
- 풍향, 거리, 명중률, 에너지와 카드 덱을 사용하는 선박·함대 전투
- 폭풍의 사각지대 일반·정예전은 최대 2척, 심연의 마지막 항로는 최대 3척이 등장하며 보스는 1척입니다.
- 역할 9종·특성 10종·등급을 조합한 선원 모집과 선원 내보내기. 갑판장은 전투 에너지와 시작 손패를 지원합니다.
- 노말·레어·에픽·레전드 등급으로 구성된 유물 22종과 유물 버리기. 에너지·드로우 관련 유물도 포함됩니다.
- 사망 또는 클리어 시 악명을 전승해 영구 능력을 강화하는 메타 성장
- 키보드와 터치/마우스를 모두 지원하는 반응형 UI
- 모든 항해 결과를 기록하고 통계로 확인·내보낼 수 있는 플레이 데이터 분석 구조

## 조작

- 항로: 지도 노드 또는 하단 항로 버튼 선택, 숫자키 `1`~`3`
- 카드 선택: `1`~`8`, 대상 이동: 방향키/Tab, 사용: `Enter`, 취소: `Escape`
- 선장 기술: `Q`, 턴 종료: `E`
- 마우스·터치에서는 카드를 함선 또는 바다의 강조된 대상 영역으로 드래그합니다.
- 선택형 조우: 선택지 또는 숫자키, `Enter`로 주요 버튼 실행
- 선원·유물 관리: 항로 화면의 `내보내기`·`버리기` 버튼

## 항로 선택과 해금

출항 전 거점 화면에서 선장과 함께 난이도가 다른 항로를 선택합니다. 각 항로는 독립된 3개 해역·보스·배색을 가지며, 적 함선의 체력·돛·인원·공격력은 항로 배율만큼, 보상 금화·악명은 별도 배율만큼 증가합니다.

| 항로 | 난이도 | 적 능력치 배율 | 보상 배율 | 해금 조건 |
| --- | --- | --- | --- | --- |
| 잔잔한 무역풍 항로 | 표준 | ×1.0 | ×1.0 | 기본 해금 |
| 폭풍의 사각지대 항로 | 험로 | ×1.3 | ×1.2 | 잔잔한 무역풍 항로 완주(승리) |
| 심연의 마지막 항로 | 극한 | ×1.65 | ×1.4 | 폭풍의 사각지대 항로 완주(승리) |

항로를 완주(해적왕 등극)하면 승리 화면에 신규 항로·선장 해금 배너가 표시되며, 해금 여부는 브라우저 저장 데이터에 영구 기록됩니다.

## 등급과 관리 규칙

선원과 유물은 공통으로 노말 55%, 레어 28%, 에픽 13%, 레전드 4%의 기본 확률을 사용합니다. 선원은 등급에 따라 역할 기본 전투력에 각각 +0, +1, +2, +4 보너스를 받고 역할 숙련 단계가 0, 1, 2, 3으로 상승합니다.

| 역할 | 노말 | 레어 | 에픽 | 레전드 |
| --- | --- | --- | --- | --- |
| 포수 | 포격·사슬탄 피해 +1 | +2 | +3 | +4 |
| 조타수 | 접근 성공률 +10% | +15% | +20% | +25% |
| 수리공 | 응급수리 선체 +3 | +5 | +7 | +9 |
| 요리사 | 이동 보급 소모 -1 | 소모 -1·사기 +1 | 소모 -1·사기 +2 | 소모 -1·사기 +3 |
| 갑판전사 | 접안 전투력 +4 | +6 | +8 | +10 |
| 감시원 | 적 명중률 -5% | -8% | -11% | -14% |
| 보급관 | 항구 구매 비용 -1 금화 | -2 | -3 | -5 |
| 군의관 | 전투 승리 시 사기 +3 | +5 | +7 | +9 |
| 갑판장 | 첫 턴 에너지 +1 | 첫 턴 에너지 +1·시작 손패 +1 | 첫 두 턴 에너지 +1 | 최대 에너지 +1·시작 손패 +1 |

선원은 역할과 별개로 굳센·주당·행운아·상처투성이·용맹한·매의 눈·미신을 믿는·무감한·절약가·분발 10종 특성 중 하나를 무작위로 갖습니다. 유물은 노말 6종·레어 6종·에픽 6종·레전드 4종, 총 22종이며 명중률·피해량 같은 수치형 효과부터 매 전투 첫 사격 명중 보장, 카드 에너지·드로우, 조우 판정 확률 상승, 접안 전투 시 선원 손실 무효 같은 상황을 바꾸는 효과까지 다양합니다.

유물 3택은 후보 한 칸마다 등급을 먼저 추첨한 뒤 해당 등급의 미보유 유물을 제시합니다. 같은 유물은 한 선택지 안에서 중복되지 않으며, 남은 유물이 없는 등급은 제외하고 확률을 재정규화합니다. 선원 내보내기와 유물 버리기는 항로 화면에서 확인 절차를 거쳐 실행되며 보상은 없습니다. 마지막 선원 1명은 내보낼 수 없습니다.

## 플레이 데이터 분석

우측 상단 `▤` 버튼(통계 보기)을 누르면 지금까지의 모든 항해 결과를 모아 볼 수 있습니다.

- 항해마다 선장, 승패, 사망 원인(선체 파손·선상 반란·항해 포기), 도달 해역, 악명, 이동 횟수, 전투당 사용한 명령, 입힌·받은 피해, 유물 등급 등을 자동으로 기록합니다.
- 기록은 브라우저 `localStorage`(`pirate-king-analytics-v1` 키, 최근 300개 항해)에 저장되며 새로고침해도 유지됩니다.
- 통계 화면에서 총 항해 수·승률·평균 악명·선장별 성과·사망 원인 분포·자주 쓴 전투 명령·최근 항해 목록을 바로 확인할 수 있고, `JSON 내보내기` 버튼으로 원본 데이터를 내려받아 스프레드시트나 별도 분석 도구에서 살펴볼 수 있습니다.
- 데이터 기록 로직은 [src/analytics.js](src/analytics.js)에 UI와 분리된 순수 데이터 계층으로 구현되어 있습니다.

## 소스 구조

```text
.
├── index.html
├── styles.css
├── src/
│   ├── analytics.js
│   ├── card-definitions.js
│   ├── card-engine.js
│   ├── fleet-combat.js
│   └── game.js
└── .github/
    └── workflows/
        └── pages.yml
```

게임은 외부 라이브러리 없이 HTML, CSS, JavaScript와 Canvas 2D API로 구현했습니다. 전승 데이터와 항해 분석 기록은 모두 브라우저 `localStorage`에 저장됩니다.

## GitHub Pages 배포

저장소에는 GitHub Pages 배포 워크플로가 포함되어 있습니다.

1. GitHub 저장소의 `Settings > Pages`를 엽니다.
2. `Source`를 `GitHub Actions`로 설정합니다.
3. `main` 브랜치에 푸시하거나 Pages 워크플로를 수동 실행합니다.

배포 주소 형식은 다음과 같습니다.

```text
https://<github-user>.github.io/<repository-name>/
```
